***********************************************************Mudando de user*********************************************************************************************************************
su-> é um comando usado para iniciar o shell como se fosse um outro user, podendo manipular os ficheiros do outro user estando num outro. O ambiente do user acessado é carregado no actual e o directório actual é mudado(para o que foi acessado remotamente).


Sintaxe:

su -l username

ex:su -l lab2

NB:Se colocarmos su - vai iniciar a sessao do shell como superuser.


***********************************************************Executando um comando como se fosse outro user*************************************************************************************
sudo-> permite que um usuário comum possa executar comandos como se fosse um superusuário.

Sintaxe:

sudo comando

ex: sudo ls /root

NB:Para começar uma sessao de superusuário fazemos sudo -i e já teremos privilégios de superusuário sem a necessidade de preceder os comando por sudo.

sudo -l -> retorna a lista de privilégios concedidos pelo comando sudo.

***********************************************************Mudando o dono do ficheiro e o grupo*************************************************************************************

chown-> comando usado para mudar o dono do ficheiro e o grupo.NB:Este comando deve ter privilégio de superuser(sudo).

Sintaxe:

chown novo_dono:novo_grupo ficheiro

ex:sudo chown master:group1 file1.txt

NB:Se quisermos mudar somente o dono ou o grupo ocultamos o que queremos manter.

ex2:sudo chown :group1 file1.txt -> mantivemos o dono e mudamos somente o grupo.

ex3:sudo chown master file1.txt -> mudamos somente o dono e mantivemos o grupo.

ex4:sudo chown master: file1.txt -> mudamos o dono e o grupo para o grupo de login do user(o nome do user e do grupo será o mesmo).


***********************************************************Mudando a password******************************************************************************************************************

passwd -> comando usado para definir password para os users.NB:Para mudar a password do user actual é só escrever o comando sem argumentos(passwd).

Sintaxe:

passwd user  -> deve ser precedido por sudo.

ex:sudo passwd lab2
