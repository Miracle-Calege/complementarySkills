Processos-> é um conjunto de programas aguardando a sua vez para serem atendidos pela CPU. Cada processo é vinculado a um número, process ID (PID), estes ficam ordenados de forma crescente.

**************************************************************************Visualizando processos***********************************************************************************************

ps-> é o comando usado para visualizar processos.


ex.output:

PID     TTY     TIME    CMD
8129  pts/0    00:00:00 bash
8173  pts/0    00:00:00 ps

NB:PID: coluna que representa o ID dos processos, TTY:teletype refere-se ao terminal de controle do processo,TIME:exibe a quantidade de tempo de CPU consumido pelo processo e CMD:exibe os processos.


Sintaxe:

ps x

NB:O comando ps com a option "x" exibe todos os processos com ou sem terminal de controle.

Sintaxe:

ps aux

NB:O comando exibe processos pertencentes a cada user.Adicionando mais colunas chamadas de BSD-style behavior

**************************************************************************Tabela de estado*****************************************************************************************************

Estado                 Significado

R			Running.O processos está em execuçao ou pronto para execuçao.

S                       Sleeping.O processo nao está em execuçao, pode estar a espera de um evento para entrar em execuçao.

D                       num estado de sleep ininterrupto, aguardando por I/O como um disk drive.


T                      Parado.O processo foi instruído a parar.


Z                      Processo extinto,é um processo filho que terminou mas nao foi "limpado" pelo processo pai. NB:Processo pai é aquele que gera outros processos, processos filhos.


<                      Um processo com alta prioridade(leva mais tempo de cpu).


N                     Um processo com baixa prioridade(leva menos tempo de cpu).
